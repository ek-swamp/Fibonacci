# Fibonacci
Implementation af Fibonacci-talrække

Master-branch indeholder de initielle test til at skrive selve koden ved brug af TDD samt tilføjet en main-metode til bergning af et tal fra rækken og måling af eksekveringstiden.
Herudover er der 4 andre branches:
- *gamintest* der sikrer at test virker, men ikke følger implementationen
- *naive* der følger definition helt slavisk
- *looping* der gør beregningen smartere i en løkke
- *recursive* der ligeledes gør beregning smarte, men ved brug udelukkende via funktionskald
